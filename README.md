# فَهْم — منصة الدراسة بالذكاء الاصطناعي

مشروع Node.js وواجهة عربية. يحتوي على شرح سبورة، رسم وممحاة، قراءة صوتية إذا توفر صوت عربي على الجهاز، تشغيل تلقائي، ملخص وبطاقات واختبار وملاحظات محلية.

## التشغيل
1. استخدم Node.js 22 أو أحدث.
2. انسخ .env.example إلى ملف .env داخل مجلد المشروع.
3. ضع مفتاحك في OPENAI_API_KEY. لا ترفعه إلى GitHub.
4. شغّل `npm start` من مجلد المشروع.
5. افتح http://127.0.0.1:3000

لا يحتاج المشروع npm install، لأنه يستخدم مكتبات Node المدمجة. لتجربة بلا مفتاح اتركه فارغًا وافتح زر «تجربة محلية» بعد تشغيل الخادم. يجب وجود .env حتى لو كان المفتاح فارغًا.
النموذج الافتراضي gpt-4.1-mini؛ يمكن تغييره عبر OPENAI_MODEL إلى نموذج متاح لحسابك يدعم Responses API والصور والمخرجات المنظمة. استخدام API يتطلب مفتاحًا صالحًا وقد يكون مدفوعًا. لم يتم اختبار التوليد الحي بمفتاح مستخدم ضمن إعداد هذه الحزمة.

## GitHub
ارفع محتويات مجلد fahm بحيث يظهر package.json وserver.mjs في جذر المستودع ومجلد public بجوارهما. لا ترفع ZIP بدل الملفات ولا ترفع ملف .env. .env.example آمن طالما أنه بلا أسرار.
GitHub Pages لا يشغّل خادم Node.js. النسخة الحالية مهيأة لواجهة وخادم على الأصل نفسه؛ نشر الواجهة وحدها على Pages يتطلب تعديل المسارات وعنوان API وسياسة CORS ومصادقة الخادم. لا تضع مفتاح الخدمة في الواجهة لحل ذلك.

## الخصوصية والأمان
الخادم لا يحفظ الدروس أو الصور كملفات، لكنه يعالجها في الذاكرة ويرسلها إلى OpenAI. يستخدم store:false؛ هذا لا يعني غياب جميع سياسات احتفاظ المزود. راجع سياسة بياناته قبل التعامل مع بيانات الطلاب. لا ترفع بيانات شخصية أو حساسة. الملاحظات محلية ويمكن مسحها وتنزيلها.
قد يخطئ الشرح أو استخراج النص. راجع الإجابات ولا تعتبر المحتوى مطابقًا لمنهج رسمي تلقائيًا. الرسم مؤقت يمسح عند تبديل الخطوة أو تغيير حجم السبورة. الصوت يعتمد على دعم الجهاز والمتصفح.
الافتراضي تشغيل محلي فقط. قبل ربط HOST بعنوان عام يجب APP_PASSWORD عشوائي بطول 16 حرفًا على الأقل؛ أدخله في الصفحة. لا تنشر الخدمة عبر HTTP عام، بل استخدم HTTPS وproxy ومصادقة مستخدمين وحصص تكلفة وحماية مناسبة. الحماية الحالية أولية (6 طلبات/IP/دقيقة وطلبا توليد متزامنان) ولا تجعل المشروع منصة إنتاج جاهزة. لا تعتمد على كلمة مرور مشتركة لمدرسة كاملة. إلغاء انتظار المتصفح لا يضمن إلغاء طلب المزود أو عدم احتساب تكلفته.

## الاختبارات
`npm test`
تختبر بنية الدرس وحدود الإجابات وليست اختبارًا لدقة الشرح أو اختبار واجهة. اختبر المتصفح والهاتف والتوليد الحقيقي قبل الاستخدام.

## الملفات
- public/index.html, public/style.css, public/app.js: الواجهة.
- server.mjs: الخادم وربط المزود والتحقق الأساسي.
- schema.mjs: مخطط المخرجات والتحقق منها.
- schema.test.mjs: اختبارات.

هذه حزمة مُعاد تجهيزها لمتابعة إعداد المشروع. لا تحتوي على مفاتيح API.
